# desk

휴대폰과 PC에서 일정과 할 일을 보고 고치는 개인 대시보드다. 데이터는 데이터베이스가 아니라 구글 드라이브 안 옵시디언 볼트의 마크다운 노트에 두어서, 옵시디언에서 손으로 읽고 고칠 수 있다.

## 누가 무엇을 만들었나

이 저장소에는 가져온 코드와 직접 만든 코드가 함께 있다.

| 부분 | 파일 | 출처 |
|---|---|---|
| 화면의 디자인과 동작 | `index.html` | '햄찌스 데스크'(노션 기반 대시보드)의 화면 코드를 가져왔다. 직접 만든 것이 아니다 |
| 화면에서 고친 곳 | `index.html` 안 `desk:` 주석이 붙은 곳 | 직접 고쳤다. 일정·할 일과 무관한 화면의 코드를 들어내고(원본의 절반 이상), 서버 연결 부분과 예시 데이터를 바꿨다 |
| 중간 서버 | `apps-script/Note.gs`, `apps-script/Code.gs` | 직접 만들었다 |
| 점검 코드와 개발용 서버 | `test/` | 직접 만들었다 |

직접 만든 부분의 핵심은 서버다. 원본 화면이 보내는 요청(`load`, `add`, `update`, `trash`, `history`, `eventAdd`, `habitToggle`)에 그대로 답하되, 데이터를 노션 대신 마크다운 노트에서 읽고 쓴다. 화면을 고치지 않고 저장소만 바꾼 셈이다.

## 구조

```
휴대폰·PC 브라우저 (index.html, GitHub Pages)
  │  { 비밀번호, 동작, 내용 }
  ▼
Google Apps Script 웹 앱 (apps-script/)
  │  비밀번호 확인 → 입력 검사 → 번호로 줄을 찾아 그 줄만 고친다
  ▼
구글 드라이브의 옵시디언 볼트 todo/ 폴더 (할 일.md, 메모.md, 습관.md, 휴지통.md) + 구글 캘린더
```

- 화면에는 데이터가 없다. 비밀번호를 넣어야 연결된다.
- 비밀번호와 폴더 ID는 Apps Script 「스크립트 속성」에만 둔다. 이 저장소에는 없다.
- 서버 주소는 `config.js`에 둔다. 비밀번호 없이는 아무것도 할 수 없어서 공개돼도 된다.
- `apps-script/Note.gs`는 구글 서비스를 쓰지 않는 순수 글자 처리라서 PC에서 Node로 점검한다. `apps-script/Code.gs`는 구글 서비스를 흉내 낸 가짜(`test/fake-google.js`) 위에서 그대로 돌려 점검한다.

## 노트 모양

`todo/할 일.md`에 한 건이 이렇게 적힌다. 옵시디언에서 직접 고쳐도 되고, 번호(`^...`)가 없는 줄은 서버가 다음에 읽을 때 붙인다.

```
- [ ] 설정 화면 글자 겹침 고치기 ^7hp9c3
    날짜:: 2026-11-25T15:00:00+09:00
    상태:: 진행 중
    프로젝트:: 업무
    우선순위:: 상
    손으로 쓴 메모 줄은 서버가 건드리지 않는다
```

메모는 `todo/메모.md`, 습관은 `todo/습관.md`, 근태는 `todo/근태.md`, 연차 총 일수는 `todo/연차.md`, 급여는 `todo/급여.md`, 지원처는 `todo/지원처.md`, 지원 서류는 `todo/지원 서류.md`, 지운 건은 `todo/휴지통.md`로 간다.

- 서버는 바뀐 항목의 줄만 제자리에서 고친다. 다른 줄의 글자, 순서, 들여쓰기는 그대로다.
- 체크 표시가 완료 여부의 정본이다. 옵시디언에서 손으로 `[x]`나 `[X]`로 바꿔도 완료로 읽힌다.
- 화면에서 완료하면 `완료일::`이 적힌다. 끝낸 지 60일이 지난 일은 대시보드에서 빠지고 업무 화면의 완료 기록에만 나온다.
- 포트폴리오 화면은 끝낸 일을 통계와 그래프로 보여 준다. 커리어 화면의 공고 적합도는 공고 문구에서 역량 낱말을 찾아 내 업무 기록과 대조한다. 규칙은 게임 클라이언트 직무 기준이다(`index.html`의 `JOB_SK`).
- 근태는 포괄임금 기준이다. 수당은 계산하지 않고 야근 시간, 택시비 정산(먼저 내고 나중에 받는 돈), 휴가와 남은 연차를 센다.
- 급여는 평소 읽기(`load`)에 넣지 않는다. 화면이 읽은 내용을 기기에 저장해 두기 때문이다. 「보기」를 누를 때만 `pays`로 따로 받아 가고, 받은 것은 기기에 저장하지 않으며 화면을 떠나면 다시 가린다.
- PC에서 고친 지 2분이 안 된 파일에는 번호를 붙여 쓰지 않는다(옵시디언이 아직 쓰는 중일 수 있어서다). 그동안 번호 없는 건은 화면에 보이기만 하고 누를 수 없다.

## PC에서 돌려 보기

```
node test/note.test.js
node test/server.test.js
node test/dev-server.js
```

마지막 줄은 개발용 서버다. `http://localhost:5173`에서 화면과 서버 코드를 붙여 볼 수 있다. 구글 드라이브 대신 임시 폴더에 노트를 쓰고 캘린더는 가짜 일정을 준다. 비밀번호는 `test/dev-server.js` 안의 시험용 값이다.

## 배포 순서 (처음 한 번)

1. **todo 폴더 만들기.** 구글 드라이브에 있는 옵시디언 볼트 안에 `todo` 폴더를 만든다. 그 폴더를 브라우저에서 열면 주소가 `https://drive.google.com/drive/folders/XXXX` 모양이다. `XXXX`가 폴더 ID다.
2. **Apps Script 프로젝트 만들기.** 볼트가 있는 구글 계정으로 https://script.google.com 에서 「새 프로젝트」를 만든다.
3. **코드 붙여 넣기.** 기본 `Code.gs`의 내용을 지우고 이 저장소의 `apps-script/Code.gs`를 붙여 넣는다. 파일 `+` → 스크립트로 `Note`를 만들어 `apps-script/Note.gs`를 붙여 넣는다.
4. **스크립트 속성 넣기.** 프로젝트 설정(톱니바퀴) → 스크립트 속성에 둘을 추가한다.
   - `PASS` = 비밀번호. 16글자 이상
   - `TODO_FOLDER` = 1번의 폴더 ID

   같은 화면에서 시간대가 서울(GMT+09:00)인지 확인한다. 다르면 종일 일정이 하루 밀린다.
5. **점검 실행.** 편집기 위쪽 함수 목록에서 `selfCheck`를 골라 실행한다. 처음에는 드라이브와 캘린더 권한을 묻는다. 실행 로그 끝에 `점검 통과`가 나오면 된다. `todo/_점검/` 폴더 안에서만 돌고 실제 노트는 건드리지 않는다.
6. **웹 앱 배포.** 배포 → 새 배포 → 유형: 웹 앱 / 실행: 나 / 액세스 권한: 모든 사용자 → 배포. 나온 주소(`…/exec`)를 `config.js`의 `url`에 넣는다.
7. **화면 올리기.** 이 저장소를 GitHub에 올리고 Pages를 켠다.
8. **휴대폰에서 열기.** Pages 주소를 열어 비밀번호를 넣고, 브라우저 메뉴에서 「홈 화면에 추가」를 누른다.

코드를 고친 뒤에는 Apps Script에 다시 붙여 넣고 배포 → 배포 관리 → 수정(연필) → 버전: 새 버전으로 올려야 반영된다. 주소는 그대로다.
